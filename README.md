# ElvUI_thingsUI

![Version](https://img.shields.io/badge/version-4.2.1-green)

## Modules
- **Aura Bars** - put a tracked buff or debuff on its own movable bar, anchor it anywhere, or drop it in Groups - Bars or the Bar Setup.
- **Aura Collections** - named aura lists (or Blizzard's own filters like Big Defensives) you edit once and every group follows.
- **Aura Icons** - Aura Bars but icons; restyle, glow, put them in Groups - Icons or right into your Essential/Utility row.
- **Bar Setup** - arrange and stack your bars into one cluster.
- **Buff Bars** - skin and anchor CDM tracked bars, grow up/down, swap font/texture.
- **CDM** - CDM stuff, anchor the Cooldown Manager to Player/Target, icon size, text and glow, aura overlay and pandemic look, racials and on-use trinkets straight into Essential/Utility, and no doubles of things you already show somewhere else.
- **CDM Spell Editor** - one CDM spell or buff at a time: custom icon, glow, aura overlay and swipe, pandemic glow, cooldown and stack text.
- **Charge Bar** - per-spec spell charge tracker, in the CDM cluster or free-floating.
- **Classbar** - per-spec ElvUI classbar where you anchor it.
- **Damage Meter** - Details anchored to right chat, or Mini Meter: our own meter on Blizzard's damage data, with split windows, breakdowns and death recaps, anchored to right chat yy you guessed it.
- **Group Icons\Bars\Text** - movable groups of spells, items, auras and Aura Icons\Bars, with visibility rules (combat, solo/party/raid, zone, form, mounted...). Text groups write auras and cooldowns as lines your way: [name] [cd], NO WILD CHARGE [cd].
- **Raid Frame Builder** - put your raid frames in your own order. Drag raid-frame-looking boxes around, sort Tank > DPS > Healer (or however you like it), keep classes together, save. Layouts follow you to every character, export/import works with things for EUI too.
- **Timers** - cast-triggered static-icon timers with auto & manual durations.

## ElvUI QoL
- **Group Frame Anchor** - party/raid frames stay glued to the corner you pick, even near the screen edge.
- Fixes ElvUI's raid frames sometimes parking the first frame of a new column one row too low after a reload or profile swap.

## Grid2
Apply bundled raid-frame profiles (NHT, FHT Icons/Squares) from the Grid2 tab.

## Installer
One-time setup: import profile and plugin things, set UI scale, pick unitframe coloring, move the minimap/auras if you want, choose dmg meter, optional extra action bar layouts, and pick between ElvUI UnitFrames or Grid2. Should pop-up on first time install, re-run it from the Import\Export tab. BigWigs and Blizzard's Cooldown Manager layouts come along. /tui alt is the Character Setup for alts (yeeees, alts): installs, shows what each character uses and loads it, ElvUI and BigWigs going FHT on healer specs by themselves.

# Installation

1. Install with wago app.
2. Install profiles with the wago installer ingame.
3. Run the thingsUI plugin installer.
4. Heal things, or not.

Settings: **/ec** -> **Plugins** -> **thingsUI**
